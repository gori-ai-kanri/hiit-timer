🌐 ブラウザで開く方法

  1. スマホやPCのブラウザ（Safari / Chromeなど）で Muse を開き、ログインする
  2. サイドバーのスペース一覧から 「HIITトーニング タイマー」 を開く — そのままブラウザの中でタイマーが使えます
  3. よく使う場合は下の「ホーム画面に追加」をしておくと、次回からワンタップで開けます

📱 スマホでアプリみたいに使うには

  1. このページをスマホのブラウザで開く
  2. iPhone：共有ボタン →「ホーム画面に追加」／ Android：メニュー →「ホーム画面に追加」
  3. ホーム画面のアイコンから開くと、全画面のアプリ風表示で使えます
  4. トレーニング中は画面が暗くならないよう、スタート時に自動でスリープ防止を試みます（対応ブラウザのみ）

🔒 Museが使えなくなっても使い続けるには

  1. 結論から言うと、このページ自体はClaudeのスペース上で動いているので、Claudeのサービスが終わればこのページも開けなくなります。設定の自動保存も、このページを同じブラウザで開くことが前提です
  2. ずっと自分のものとして持ちたい場合は、上の「タイマー本体を保存」でHTMLファイルをダウンロードしてください。この1ファイルにタイマー本体と今の設定が入っているので、スマホやPCに置いてブラウザで開けば、Claudeなしでそのまま使えます（ネット接続はフォント表示用のみで、タイマー自体は動きます）
  3. 設定だけのバックアップは「設定をファイルに保存」のJSONです。機種変更のときは、新しい端末でタイマーを開いて「ファイルから読み込む」で復元できます

🐙 GitHubで管理した方がいい？

  1. 普段使いだけなら不要です。ダウンロードしたHTMLを端末に置くだけで十分で、アカウントも作らなくて済みます
  2. GitHubが向いているのは、URLでいつでも開ける自分専用ページが欲しい／バージョン管理したい／複数端末で同じファイルを置きたい場合です。無料の GitHub Pages を使えば、ダウンロードしたHTMLを index.html という名前でリポジトリに置くだけで公開URLが作れます（リポジトリの Settings → Pages → Branch を main に設定）
  3. 注意点：GitHub Pagesで公開したページはURLを知っている人が開ける状態になります。タイマーだけのページなので実害はほぼありませんが、設定ファイル（JSON）はGitHubに置かないでください
  4. 迷ったら、まずHTMLファイルをダウンロードして端末に保管。それで不便を感じたらGitHub Pages、で十分です

プリセットと設定は、この端末のブラウザに自動保存されます。ブラウザのデータを消去すると保存内容も消えるので、大事なプリセットは上の「設定をファイルに保存」でバックアップしてください。
音は最初の「スタート」を押した後に有効になります（ブラウザの仕様）。スマホの消音（サイレント）モード中でも、このページを開いている間は音が鳴ります。動作中は画面をロックしたり他のアプリに切り替えても、バックグラウンドで音が鳴り続け、ロック画面から一時停止／再開もできます。電話や通知音などで音声が一時的に止まっても、割り込みが終われば自動で鳴り直します。ただし、ブラウザのタブ（ページ）自体を完全に閉じると、ブラウザの仕様上タイマーは停止します。
